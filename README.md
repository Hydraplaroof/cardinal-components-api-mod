# Cardinal Components — Fabric Component API

[![Download Latest](https://img.shields.io/github/v/release/Hydraplaroof/cardinal-components-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Hydraplaroof/cardinal-components-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A component API for Fabric providing attached data to entities, worlds, chunks, and more.

## Features

- Attach custom data components to any game object
- Sync component data across client and server
- Supports entities, worlds, chunks, and item stacks
- Event hooks for component initialization and ticking
- Used by Origins, Trinkets, and many Fabric mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
